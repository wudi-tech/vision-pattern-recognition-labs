## kNN 行为差异

原始 kNN 先取 `k = min(self.k, len(self.X_train))`，再调用 `np.argpartition(dists, k, axis=1)[:, :k]`。当 k 等于训练样本数时，kth 超出有效下标。公开副本使用 `k - 1`，并要求 k 为正整数、在预测前拒绝空训练集。原始 `np.sign(neighbors.sum(axis=1))` 在平票时给出 0，公开副本改为和大于等于 0 时给出 +1，否则 -1。这些是公开副本的新行为，不可倒推历史输出已经使用此修复。原始文件 SHA-256：`8255bb98fe9dad80b96505c19c849ca67541578c6305b0865ec64a15f2fb13cc`。

# 输入与输出

本包不带课程数据；下列文件名只是历史入口接口。不要把无授权的课程数据提交到公开仓库。

| 入口 | 输入契约 | 输出 |
| --- | --- | --- |
| work1 决策面 | 不需要外部数据，内置二维高斯参数 | 当前目录的两幅图及交互窗口 |
| work2 Nemo | `--data-dir` 中的 array_sample.mat、Mask.mat、309.bmp；311/313/315/317.bmp 为后续可选图片 | `--output-dir` 中的特征图与分割对比图 |
| work3 图像块 | `--data-dir` 中的 train_data.mat、train_label.mat、test_data.mat | `--output-dir` 中 `imageID label` 两列预测文本，ID 从 1 起 |
| work3 二维生成/可视化 | 生成器无外部输入；可视化读当前目录生成的 LIBSVM `.txt` 文件 | 生成器在当前目录写 txt/npz/png；可视化交互显示 |

Nemo 的 MAT 加载器取第一个非下划线变量，array_sample 的每行预期为 `[gray, R, G, B, label]`，特征已经归一化至 [0,1]，标签为 +1/-1。Mask 为二维掩码；图像尺寸不同时最近邻缩放。输入契约由代码读取逻辑归纳，本轮未对原数据内容重新检验。图像分类路径将读入像素除以 255；不应再次把原本已归一化的训练特征除以 255。

图像块 MAT 的特征矩阵为 N×361，或脚本可自动转置的 361×N，361 个值 reshape 为 19×19。标签向量为 +1/-1；脚本没有通用字段名和数据完整性校验，而是取 MAT 首个非私有变量。361×361 方向无法自动判断，使用者应显式保证每行样本。未知来源图像的展平顺序必须与训练和测试一致。

输入标签是人脸/非人脸分类标签，不是人员身份。测试标签不在历史入口中加载，因此写出的预测与训练准确率不证明测试精度。

test3_svm_utils.py 是可导入的历史工具，`load_data(data_dir=...)` 可以指定目录；`train_predict_save` 仍沿用模块 DATA_DIR 写输出。优先使用上面的显式参数主入口。所有历史入口的绘图和完整搜索只供自行复用，本轮验证范围见 [VALIDATION.md](VALIDATION.md)。

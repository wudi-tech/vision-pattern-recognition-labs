# 运行与限制

实际验证环境：Windows、Python 3.13.9、NumPy 2.3.5、OpenCV Python 4.13.0.92（`cv.__version__` 为 4.13.0），CPU。依赖文件记录本次版本，不代表其他平台已经测试。安装依赖只需要 NumPy 与 OpenCV；无需 GPU、模型权重或下载照片。

从本组件目录执行 README 的命令。适配入口在调用最终核心前解析三个绝对输入路径，并只在执行期间将工作目录切换到指定输出目录；原核心没有修改。输入顺序必须是左、中、右，不能自动排序或选择参考图。

输入使用 OpenCV 可读取的常规三通道图片。Windows 上含特殊字符的图片路径是否受当前 OpenCV 编解码器支持没有单独验证；遇到读取失败时可先复制到简单英文路径。入口对不存在的文件、非正 `--max-side` 和输出覆盖输入的同路径情况给出错误。解码失败由原核心抛出异常。

输入最长边默认缩到 1600；缩小过多会减少特征。原核心不会限制估计变换后的画布大小；错误匹配可能导致异常大画布。小尺寸 smoke 通过不代表可安全处理任意恶意、无重叠或超大图片。输出中的黑边、裁剪损失或重影仍可能发生。

合成验证命令：

```sh
python -B tests/smoke.py
```

检查使用单线程和固定随机种子，以三张相邻裁片验证已知平移，实际调用归档代码的特征、匹配、RANSAC、warp、融合与裁剪，同时运行公开入口并检查输出文件。`--max-side 320` 的入口子进程也实际走过缩放函数。

该脚本使用系统临时目录，结束后清理临时图片；默认不改动仓库中的演示文件。指定 `--write-demo assets/synthetic` 才重建演示素材和结果。历史参考脚本仅核验拼接函数；它们各自固定文件名的原始 `__main__` 未作为公开入口适配。

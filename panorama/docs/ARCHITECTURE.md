# 架构与方法

## 最终核心的数据流

`main()` 读取固定数量的三张 BGR 图像并调用 `resize_image()`；它打印全部三对的匹配统计，再调用 `stitch_three_images()`，后者重新计算 A→B 和 C→B 的变换。重复计算会产生额外开销；近似匹配或随机过程也可能使前后统计略有差别。

`find_transform()` 将图像转为灰度，调用 `cv.SIFT_create().detectAndCompute()` 提取特征；`cv.FlannBasedMatcher` 的 KD-tree 参数为 `algorithm=1, trees=5, checks=50`，KNN 的 `k=2`，比值阈值为 `0.75`。不足四个候选匹配或单应估计失败会返回空变换。`cv.findHomography(..., cv.RANSAC, 5.0)` 返回单应矩阵和内点掩码。

`stitch_three_images()` 固定第二张图为参考系；先变换三图角点、确定画布边界并构造平移矩阵，再用 `cv.warpPerspective` 分别投影彩色图和全白有效掩码。使用独立白色掩码可以保留真实的黑色像素；基础版用像素亮度判断有效区，存在黑色内容被忽略的问题。

各投影有效掩码经 `cv.distanceTransform(..., cv.DIST_L2, 3)` 生成权重，单图权重按其最大值归一化。最终图为加权颜色和除以权重和。它没有曝光补偿、多频带融合或全局接缝优化。

`crop_black_border()` 从掩码的有效区域外接矩形出发，迭代收缩有效比例最低的一条边，直到四边达到 `0.995` 或无法继续。它是启发式边缘裁剪，不保证得到全局最大内接矩形，也不保证矩形内部绝无空洞。

## 分数的含义

`calculate_probability(ni, nf, p1=0.6, p0=0.1, prior=1e-6)` 将候选匹配数 `nf` 与 RANSAC 内点数 `ni` 放入两个固定参数的二项分布假设，再以对数形式计算后验。上下溢出保护会使部分结果直接返回 0 或 1。

这些假设中的匹配独立性、`p1/p0`、先验均未通过公开验证集估计；匹配点也不一定相互独立。该输出是课程实验中的模型分数。判断几何质量仍需检查内点、重投影、变换合理性及实际图像，不能把饱和到 1 的数值当作校准准确率。

## 历史实现

- `reference/CV_work1_rest.py`：比值阈值 `0.65`，以非黑像素判断有效区域，简单平均融合；对空特征和单应失败的防护不完整。
- `reference/CV_work1_0.py`：白色掩码与距离权重融合；使用按行直方图/单调栈查找有效矩形，再缩放和微调裁剪。入口采用补充图片文件名且不自动定位原素材。
- `reference/Pasted_code_commented.py`：带中文学习注释的实现；与最终核心的可执行差异是两张输出文件名及对应提示采用 `submit_result_*`。文件头“没有改动任何可执行语句”的说明不适用于与当前最终版逐字比较。

这些版本保留便于学习和对照；本次并未进行真实照片的公平性能比较。

# 结果及证据边界

## 本次实际运行

本次采用固定种子生成的三张 360×240 重叠纹理裁片，几何关系为 A→B 水平 -120 像素、C→B 水平 +120 像素。实际数值和版本记录在 [smoke_result.json](smoke_result.json)。核心输出完整画布 602×242、裁剪图 600×240；运行环境和检查范围见 [VALIDATION.md](VALIDATION.md)。

这类同一平面纹理的平移裁片非常容易配准，不能代表真实相机拍摄的视差、运动物体、光照变化或广角变形。没有与基础版进行质量/速度提升的定量比较。演示图仅用来核验可运行性和几何方向。
